# 整理基础规则时的核对顺序

《基础知识》涵盖回合节奏、能量与拍卖、公共牌库、英雄成长、装备、天赋、锦囊和实战观察。收入、概率、人数、牌库数量与战斗上限属于机制数值，按当前知识与来源比对。前中后期的划分是教学框架，整理成策略时保留各阵容实证的启动时机。

同一结论先确定阶段、操作对象和等级类型。棋手升本影响卡阶与人口，英雄合成、觉醒影响英雄成长，整备在下一次准备阶段触发，临时等级在当轮计入战力。记录觉醒回手、出售退场、阵亡牺牲各自的触发与资源变化。转级类效果还要记录永久等级与临时等级、候选数量、站位和随机范围。

文档中的装备、英雄或天赋例子需要核对正式名称、适用形态和叠加限制。对照同主题已有笔记，分清基本规则、特殊交互和实战取舍。盾、免伤、反伤及直接消灭分别验证，特例要写明是哪一种护盾和哪一段伤害。正文采用当前核实的口径，冲突及来源段落留在附件或核查记录。
