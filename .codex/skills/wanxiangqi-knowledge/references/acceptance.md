# 验收场景

网页升级额外验收：中文迁移幂等、同名中文序号与非法字符、手写旧文及证据保留、阵容 JSON/Markdown/索引一致、人工章节和 meta 导入保护、版本冲突、写锁与事务恢复、并发读请求、来源链接去重及分 P、处理与沉淀状态分离。运行扩展 Python 测试及 `frontend` 下 `npm test`、`npm run build`。

浏览器检查完整窗口及 420px 侧栏：阶段切换保持打法、禁用阵营多选及待确认结果、后期和针对策略速查、编辑预览/取消/保存、未保存提醒、全笔记分类与关联跳转、来源登记及修改。浏览器测试数据仅放隔离目录，不能把示例策略或来源加入实际知识库。

执行项目虚拟环境中的 `python -m unittest discover -s .codex/skills/wanxiangqi-knowledge/tests -v`，然后用真实攻略导入验证语义输出。单元测试的模拟内容仅在隔离临时目录出现，不进入正式知识库。

| 场景 | 观察结果 |
|---|---|
| 多链接中一个412 | 保留失败原因，继续其他来源；失败来源未完成 |
| 同音词对应两个实体 | 原文保留，候选可查，没有错误全局替换 |
| 视频未提第二、第三轮拍卖 | 两轮写“暂无已确认的通用策略”，没有补写预算或轮数 |
| 讲解夹杂当局操作 | Codex拆分段落；有理由与适用条件的规则保留，单局选择留内部报告 |
| 新提交含match_action或缺少kind | 拒绝入库，已有知识不改变 |
| v1和v2策略相反 | 内部保留版本及时间段，正文集中说明实际策略差异 |
| 知识输出简化 | 无来源前缀、视频链接、时间戳引用或图片证据；保留适用条件、推测说明和本地关联链接 |
| 编辑已有知识措辞 | 原结论被替换，内部证据不丢失；重放导入不恢复旧文本或增加重复结论 |
| 同一来源重复提交 | Markdown与索引无重复来源，不产生无谓重写 |
| 两阵容共享英雄 | 检索命中相关旧知识，Codex检查语义补充，双向链接更新 |
| 来源只有metadata而无ASR | 结论提交被拒绝 |
| 原始ASR已生成、纠错中断 | 恢复纠错而不重新下载/识别 |
| 提交写到一半中断 | 待提交JSON可重放，内容幂等 |
| 同名手写Markdown未纳入索引 | 拒绝覆盖，提示先迁移 |
| 官网部分接口失败或列表缩短 | 旧实体保留，报告错误与缺失类别 |
| 棋手技能预览嵌套英雄 | 英雄仍归英雄，只有类型7牌归棋手技能 |
| 流传输提前结束 | HTTP Range恢复并校验完整字节数 |
| 审核记录仅approved=true | finish拒绝，要求核对区间覆盖所引用证据 |

真实视频验收用 `BV1aThi6AEAC`：完整音视频与页面时长一致、本地large-v3转写、关键帧核对、自动归类生成知识、术语纠错留痕、第二次导入幂等。模型下载成功不等于转写通过，单元测试通过不等于真实视频验收通过。
