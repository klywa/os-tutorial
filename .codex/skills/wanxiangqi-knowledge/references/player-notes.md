# 棋手笔记

## 章节与内容边界

正文顺序为：技能 → 前期思路 → 适用打法与选择 → 适用技巧 → 关联知识。保留既有标题、路径和稳定ID。旧“使用技巧”归入“适用技巧”；删除“适配阵容”标题，其有效内容迁入选阵说明，不直接删结论。尚无完整教学的打法留在“其他已知方向”，说明未整理范围，不创建虚构阵容链接。

“前期思路”面向尚未定阵的局面：技能使用、过渡质量、经济与升本、观察来牌及定阵信号。先核实建议能否跨阵容成立；仅在某阵容中成立的速五、固定名单或卖血路线继续放在该打法。可从已有机制与策略推导时保留条件并标记inference；不足以概括时明确通用开局尚待确认，并在交付中列缺项。不能把一场胜利当作棋手前期必强，也不能因一个阵容后期成长高就断言棋手所有阵容后期都强。

“适用技巧”保留技能操作、资源管理及跨阶段技巧；专属阵容的技巧注明条件。与前期思路重复的内容合并，有不同阶段含义的复合结论可拆分并记录derived_from。技能机制与技巧的来源、人工历史保留。

## 组合阶段强度的同源数据

沿用schema5，阶段强度保存在对应阵容`meta.player_branches[].selection.stage_strength`，可选键为early/middle/late。每阶段保存text、claim_refs和inference；依据只能引用该棋手可用的共通或专属结论。未整理的阶段允许缺失或空text，阅读显示待补充。人工修改某阶段只清除该阶段旧依据并记录人工来源，原依据留在编辑历史；其他阶段保持原样。

棋手的`lineup_adaptations`是统一保存流程生成的投影，不单独维护一份阶段判断。每套打法以“阶段强度”小节列出前中后期定性说明：现有战力、组件／成长条件、强势窗口与空窗风险。不打分，不编造回合、等级、相对胜率；只有来源明确时才使用具体门槛。资源或技能未来收益不等于当轮战力；不同开局、技能路线的条件分别说清。

编辑原有选阵表格时保留stage_strength等未涉及字段；新版表格提供前中后期强度行。引用合并、删除或分支复制时同步重映射，禁止引用其他棋手的专属结论。新旧章节名不能同时保存相互冲突的正文；保留草稿并提示合并。

## 保存与验收

复用已有资料时，不默认补采或同步官网。先恢复事务和检查外部Markdown同步问题，再保存迁移前快照；通过统一事务维护索引、棋手Markdown、受影响阵容JSON、分支文件／同步基线和重放输入。不能仅手改棋手Markdown。

核查五章节顺序、旧选阵独有内容及来源／人工保护／稳定ID；每个组合三阶段说明或明确缺项；分支更新同步棋手摘要；旧编辑保留新增字段；重复生成不增长；网页、Markdown与导出同源，旧章节定位兼容。运行相关测试、构建、skill格式校验及wxq validate，交付逐棋手缺项、实际证据范围和未决冲突。棋手Markdown若不在现有自动回读范围，不宣称已支持直接修改回读。
