# 游戏基础与实战问答

从《基础知识》查回合、经济、牌库、养成、装备和战斗的完整说明，再到《游戏机制》核对具体规则。回答局面题时先区分棋手等级、英雄品阶、英雄等级和人口。棋手等级决定商店能出现的最高品阶，升到 3 级和 5 级增加基础人口。英雄达到 10、40、100 级可能出现能力跃升，临时等级也能在当轮越过节点。

先判断本轮能兑现什么。上阵、换位和装备会改变本轮战斗，整备等下一次准备阶段，开团到开战才结算。觉醒会把英雄收回手牌，需要考虑重上位置。分析转级先看永久与临时等级，再确认供级者、接收候选和站位。遗志送给随机英雄，传承在低等级英雄中分配，换帅找最近的三分之地英雄。

评价保血、搜牌与升本时，同时看对手的实战压力、手中可兑现的战力、牌库竞争和下一阶段所需能量。只有卡牌的阵营、触发条件和目标确定后，才给具体的装备或站位操作。己方战败的原因可能是主力放不出技能、前排扛不住或输出类型被针对。
