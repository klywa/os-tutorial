# 实战条件与收益

准备阶段可以上阵、调整站位、穿戴和转移装备、打出效果牌。战斗开始后仍可买牌、刷商店和升棋手等级，但本轮部署已经完成。解释升棋手时分别核对经验差额、剩余能量和这次升本真正解锁的牌阶或人口。玩家等级、英雄品阶、英雄等级和场上人数各自判断。

登场、夺取和穿戴可以立即改变战力。整备要等下一次准备阶段，开团在开战时结算，牺牲要等阵亡，退场来自出售。觉醒后英雄会回到手牌。当前回合急需战力时，要核对动作完成后真正留在场上的作战单位。

英雄 10、40、100 级可能改变技能或关键属性，临时等级也能跨节点。解释保血或终局集中等级时，根据具体打法判断哪些信号能证明等不起或确实能提升本轮战力。读 `src/condition/catalog.json` 与 `docs/template-library.md` 核对血量、容错数、回合数、当前对手与最强对手的主C及最高等级英雄。应对即将交战的对手取当前对手，评估全场威胁才取最强对手。未知数据应让具体组不命中。文档中的前中后期是教学分段，不能直接当成所有阵容的血线或转阵门槛。

传承、遗志、换帅的目标各有规则。写“等级给主力”前，核对在场候选及其等级、阵营、站位和实际受益者。装备按承伤、首次施法、持续输出或针对对手的收益解释，核对唯一、不可拆卸和战斗触发限制。出处为《基础知识》的英雄成长、等级分配、装备和实战章节，涉及具体牌时仍回查其证据。
