# 按 case 定向生成与独立评审

## 给生成者的题目

自进化评测以参考模板组为单位。由独立整理者为每个 case 编一份题面，保留固定题号。26 个参考组必须对应 26 道题。即使多题出自同一来源，也分别交付各题的知识和方向。

- **已核实的知识**：给出本题相关实体、作用关系、必要局面、收益、兑现时机和不确定性，附可追溯的笔记条目、卡面或视频时间。整理者先查清原始资料，用足够独立作答的文字概括。涉及多种效果时，明确本题知识能够支持到哪里。
- **本题方向**：明确要解释什么决策、为什么这个方向值得讲，必要时明说购买、选择、使用、分配或放弃的动作。把选择对应正式事件、使用哪个参数、如何构造可观测条件、用什么骨架、怎样播报留给生成者。
- **答案隔离**：题面不带 golden 播报、原组名、参考条件表达式和前后说明。生成者只拿本题知识与方向、正式目录、本版规范和除去案例的已确认骨架，不自行从长篇原文发掘题目。若题面缺关键知识，标记问题并退回整理者补证；修订题面须登记版本、说明受影响的轮次。

## 每题的结果

发出当题首稿请求前，按[生成规程](generation.md#撰写复核与交付)注入本轮冻结的完整写作策略，再归档实际请求。每题使用同一轮策略全文。

每批实际调用 Gemini，先审条件，再由 Gemini 分别生成五段话术构思与首批 16 句，归档两次请求与状态。候选先审核是否合格，再选最多 3 条最佳句和 3 条实质差异句。0 句也交卷，不回送重写。评审逐题另列「用词与句式」，直接摘出同一意思在 golden 与生成稿中实际使用的短语，至少明确「原词／生成词／差别／保留或淘汰」；比较动词与宾语的搭配、主语与指代、正式术语、句序、口语语气和独立听感。意思说对但搭配不自然仍然淘汰；同义表达若同样自然准确可以保留，发现生造错词直接淘汰。通过正式条件求值和写对了机制均不能抵消错词。每轮首页注明实际生成模型及调用凭据位置。逐题完成「正式事件 → 本事件已有骨架 → 自然语言条件和正式表达式 → 五段独立构思 → 一次 16 条不同候选 → 独立审核并收录最多六句」。每句以单独播报的最终质量为准，尝试改善相邻话术只帮助打磨。关联事件另作检查，其结果单列，不能替代指定方向。遇到事件暂停、正式签名缺失、骨架未匹配、关键条件不可观测或证据不足时，保留该题号，以明确原因交卷，不能默默漏题、改答另一方向或假造条件。

## 迭代方法

封存题面、旧版和本轮生成规则。用相同26份题面分别评测；比较旧版和新版时确保各自看到同一知识与方向。曾用“给整批原文、重新提取决策点”得到的结果单独存档，不参与本题型的命中率或连续轮次判断。生成结果封存后，由独立评审读参考，逐题检查事件、条件、受益者、收益时机、误播反例及中文表达。分别给出事件与语义对齐、用词与句式质量、两项均过的结果，禁止用命中率或句子数量代替措辞评价。分别统计逐题作答、可交付成品、正式求值通过和与参考的语义一致程度。相同题号有多种正确写法时按事实和决策收益判断。

评审向规则作者回传跨题可推广的差异和改进预期。仅改通用或事件专属的标准与策略。骨架与案例在同一轮系冻结；用户明确增补时记录版本，重新建立可比基线。按相同题面重跑，保留各轮实际规范与产物。连续两轮无实质改善时停止，说明最佳成品及剩余差异。

## 每轮交给用户检查

每轮封存后即向用户展示：当轮各题的全部最终入选原句、相对上轮的具体差异、下一轮要改什么及如何验证，并链接本轮独立检查稿。主检查稿和措辞对照稿都在每题开头单列全部最终入选原句，每条保留首批序号和完整正文。零入选写明 0 句。原句清单放在逐条淘汰原因之前，按最终模板包及原始响应逐项核对。检查稿发出后继续，用户可随时纠偏。

用标题和列表逐一列出26道题；每题提供题面知识与决策方向、参考原句、实际事件和条件、全部实际入选句、差异及原因，附该批16条候选和筛选记录的链接。区分可播成品和仍待处理的工作稿。缺少成品的题也必须出现。轮末归纳可推广的优化方案，附实际正式求值结果及可浏览的评审页。含参考答案的检查稿仅供用户和独立评审阅读。

每份阶段报告（包括 HTML 主报告和措辞对照稿）在开头列出从第 1 轮至当轮的历轮统计。逐轮提供首批候选总数、入选题数和句数、理由完整与部分及零入选题数、通过的场景校验数。旧版基线单列原始筛选范围；指标口径纠正时同步修订后续各轮报告。
