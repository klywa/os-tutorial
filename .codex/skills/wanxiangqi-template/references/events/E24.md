# 解释为何建议向某阵容发展

工作表位置：personal/OS解释.xlsx「事件」第 25 行。事件编号 E24。

正式签名：`解释为何建议向某阵容发展(arg1: 阵容)`

工作表动作：向【arg1：阵容】方向发展

## 事件标准

点出已满足的定阵条件，并明确建议的目标阵容。

## 话术策略

结合局势、棋手和阵容打法，解释为什么现在适合走该阵容，原因包含但不限于：
    a. 已经或提前拿到关键英雄、装备、天赋
    b. 契合本局棋手
    c. 克制已经能识别的主要敌人，顺应当前对局的压力（例如前期压力局，拼后期局等）
话术结构：先简明说出原因（点出一个原因即可），然后显式建议向该阵容发展

## 骨架库

- **E24-S01** 阵容+某个定阵条件被满足 → 点出被满足的条件，建议向【阵容】发展。
- **E24-S02** 阵容+某几个定阵条件被满足（遍历所有可能性） → 点出被满足的条件，建议向【阵容】发展。
