# 解释为何转移装备

工作表位置：personal/OS解释.xlsx「事件」第 16 行。事件编号 E15。

正式签名：`解释为何转移装备(arg1: 英雄, arg2: 装备, arg3: 英雄)`

工作表动作：将【arg1：英雄】的【arg2：装备】转移给【arg3：英雄】

## 事件标准

核对转出者、接收者和装备，说明此次调整的收益。

## 话术策略

1. 正常转移
    a. 如果转移的装备适合接收的英雄，则结合局势、棋手和阵容打法，解释装备为什么合适
2. 满装备腾挪（包括手牌中、包括未合成的基础装备）
    a. 解释新装备为什么合适
    b. 解释旧装备给另一位英雄是否合适
    c. 解释为何三选一挪走的是这件旧装备（可选）
    d. 解释旧装备为何不合适（可选）

## 骨架库

- **E15-S01** 装备+接收装备的英雄 → 装备对英雄的效果
- **E15-S02** （装备有特殊使用技巧）装备+（接收装备的英雄）+专门的局势条件 → 结合局势解释装备的作用
- **E15-S03** 装备+转出装备的英雄+手牌 / 场上有转出装备英雄的合适装备 +转出装备的英雄装备槽位已满 → 解释是为了给转出装备英雄腾出空位接收合适的装备
