# 解释为何锁定商店

工作表位置：personal/OS解释.xlsx「事件」第 22 行。事件编号 E21。

正式签名：`解释为何锁定商店()`

工作表动作：锁定商店

## 事件标准

指出商店中的锁定对象和用途，避免只讲能量不足。

## 话术策略

结合局势、棋手和阵容打法，解释锁定的目标是什么以及目标的作用（不要解释因为能量不够）：
1. 如果锁定目标是英雄，则同【购买英雄】
2. 如果锁定目标是效果牌，则同【购买效果牌】

## 骨架库

原表规定「目标是英雄：同【购买英雄】+目标英雄在商店的条件」「目标是效果牌：同【购买效果牌】+目标效果牌在商店的条件」。下面逐项展开到本事件，判断时从商店确定锁定目标。

- **E21-S01** 目标英雄在商店 + 英雄+阵容  → 英雄在阵容中的作用
- **E21-S02** 目标英雄在商店 + 英雄+阵容+场上英雄 / 手牌英雄 → 英雄之间的联动关系
- **E21-S03** 目标英雄在商店 + （英雄有特殊功能） → 说清楚英雄的功能
- **E21-S04** 目标英雄在商店 + （英雄有特殊使用技巧和注意事项） → 说清楚使用技巧和注意事项
- **E21-S05** 目标英雄在商店 + （当前阵容不需要该英雄）场上已有该英雄 + 打出能获得效果锦囊 → 说出可以获得效果锦囊
- **E21-S06** 目标效果牌在商店 + 效果牌+阵容 → 解释效果牌在阵容中的作用
- **E21-S07** 目标效果牌在商店 + （效果牌有特殊的使用技巧）效果牌+阵容 → 解释效果牌在阵容中的作用+使用技巧
- **E21-S08** 目标效果牌在商店 + （效果牌有特殊的使用局势）效果牌+（阵容）+专门的局势条件 → 结合局势解释效果牌的作用
