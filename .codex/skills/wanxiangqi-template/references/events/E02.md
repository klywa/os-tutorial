# 解释为何上阵英雄

工作表位置：personal/OS解释.xlsx「事件」第 3 行。事件编号 E02。

正式签名：`解释为何上阵英雄(arg1: 英雄)`

工作表动作：上阵【arg1：英雄】

## 事件标准

说明为什么此刻上阵这名英雄。

## 话术策略

1. 结合局势、棋手和阵容打法，解释英雄的作用，并且
    a. 如果需要注意站位，进行提醒。
    b. 如果是功能性英雄，解释为何现在上阵
    c. 如果需要指定特定目标，需要说明

## 骨架库

- **E02-S01** 英雄+阵容  → 英雄在阵容中的作用
- **E02-S02** 英雄+阵容+场上英雄 → 英雄之间的联动关系
- **E02-S03** （英雄有特殊功能） → 说清楚英雄的功能
- **E02-S04** （英雄有特殊使用技巧和注意事项） → 说清楚使用技巧和注意事项
