# 解释为何使用棋手技能

工作表位置：personal/OS解释.xlsx「事件」第 18 行。事件编号 E17。

正式签名：`解释为何使用棋手技能(arg1: 棋手技能)`

工作表动作：使用【arg1：棋手技能】

## 事件标准

说明该棋手技能此时生效的实际收益。

## 话术策略

结合局势、棋手和阵容打法，解释该棋手技能的效果。可追加：
    a. 为何此时使用

## 骨架库

- **E17-S01** 棋手技能+阵容 → 结合阵容解释该技能的作用
- **E17-S02** （技能有特殊使用技巧）棋手技能+阵容+专门的局势条件 → 结合阵容、局势解释该技能的作用
