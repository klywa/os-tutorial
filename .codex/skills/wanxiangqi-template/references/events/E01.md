# 解释为何购买英雄

工作表位置：personal/OS解释.xlsx「事件」第 2 行。事件编号 E01。

正式签名：`解释为何购买英雄(arg1: 英雄, arg2: Array<英雄|效果牌>)`

工作表动作：从商店购买【arg1：英雄】（未选择【arg2：Array（英雄，效果牌）】

## 事件标准

说明这名英雄在当前阵容或局面中值得买的原因。

## 话术策略

结合局势、棋手和阵容打法，解释为何购买英雄
1. 如果是阵容所需的英雄，解释英雄在阵容中的作用
2. 如果是一些特殊作用的英雄（如用来刷牌、刷棋手技能、提供等级、提供额外效果），解释卡牌的作用和使用方式（包括是否需要觉醒、何时上场、何时出售）
3. 如果和已经在场上、手牌里的英雄有联动，可以点出联动。
4. 如果不属于上述任一情况，但是购买并打出可以因为凑满合成次数获得效果锦囊，则说明目的是获得效果锦囊。

## 骨架库

- **E01-S01** 英雄+阵容  → 英雄在阵容中的作用
- **E01-S02** 英雄+阵容+场上英雄 / 手牌英雄 → 英雄之间的联动关系
- **E01-S03** （英雄有特殊功能） → 说清楚英雄的功能
- **E01-S04** （英雄有特殊使用技巧和注意事项） → 说清楚使用技巧和注意事项
- **E01-S05** （当前阵容不需要该英雄）场上已有该英雄 + 打出能获得效果锦囊 → 说出可以获得效果锦囊
- **E01-S06** （英雄有特殊功能）英雄+专门的局势条件 → 解释英雄在当前局势下的作用。

命中这条骨架时，在「说明与依据」分别注明特殊功能的来源、行动前可观察的局势条件，以及该功能在此局面带来的具体收益。
