# 解释为何穿戴装备

工作表位置：personal/OS解释.xlsx「事件」第 14 行。事件编号 E13。

正式签名：`解释为何穿戴装备(arg1: 英雄, arg2: 装备)`

工作表动作：给【arg1：英雄】穿戴【arg2：装备】

## 事件标准

穿戴基础装备不解释；其余装备落实到穿戴者的作用。

## 话术策略

1. 如果是穿戴基础装备，不解释
2. 穿戴普通装备、特殊装备、天赋装备，结合局势、棋手和阵容打法，解释装备的作用（结合英雄的特点）

## 骨架库

- **E13-S01** 装备+英雄 → 装备对英雄的效果
- **E13-S02** （装备有特殊使用技巧）装备+（英雄）+专门的局势条件 → 结合局势解释装备的作用
