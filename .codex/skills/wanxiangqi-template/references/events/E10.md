# 解释为何选择效果牌

工作表位置：personal/OS解释.xlsx「事件」第 11 行。事件编号 E10。

正式签名：`解释为何选择效果牌(arg1: Array<效果牌>, arg2: 效果牌)`

工作表动作：从【arg1：Array（效果牌）】中选择【arg2：效果牌】

## 事件标准

在实际候选牌中说明所选牌能解决的问题。

## 话术策略

结合局势、棋手和阵容打法，解释为何选择该效果牌，解释为什么拿这张牌（其他牌不适配？它的什么收益、哪个效果让我们要选它？临时提升？省钱？），并追加：
    a. 给谁用
    b. 是否需要囤：1）现在选择它的原因是（其他的不适配，先存着）；2）需要囤的话什么时候（要囤几回合）时机（攒够几张、等有什么牌了、哪个英雄来、阵容人数到多少等前提）用

## 骨架库

- **E10-S01** 效果牌+阵容 → 解释效果牌在阵容中的作用
- **E10-S02** （效果牌有特殊的使用技巧）效果牌+阵容 → 解释效果牌在阵容中的作用+使用技巧
- **E10-S03** （效果牌有特殊的使用局势）效果牌+（阵容）+专门的局势条件 → 结合局势解释效果牌的作用
