# 解释为何棋手升级

工作表位置：personal/OS解释.xlsx「事件」第 20 行。事件编号 E19。

正式签名：`解释为何棋手升级(arg1: int)`

工作表动作：升级棋手到【arg1：数值】等级

## 事件标准

核对升级后的实际等级与当前阵容的目标等级。

## 话术策略

结合局势、棋手和阵容打法，解释为何此时要升级：
1. 如果目标等级是要开始刷牌的等级，讲解要刷谁，需要拿几张（拿1张就够 / 凑觉醒 / 有就拿），投入多少资源
2. 如果还需要继续升级，告知运营策略，目标是升到几级之后干什么
3. 如果目标等级是6级，可以介绍专属天赋的作用

## 骨架库

- **E19-S01** （升级后的等级还不是目标刷牌等级）棋手 / 阵容 + 当前等级 → 说明目标等级是几级（几级开始刷牌、找牌）
- **E19-S02** （升级后的等级是目标刷牌等级）棋手 / 阵容 + 当前等级 → 说明升级之后要找哪些牌，如何投入
- **E19-S03** （升级后是6级）棋手 / 阵容 + 当前是5级（升级之后是6级） → 结合棋手、阵容打法，说明专属天赋的作用
