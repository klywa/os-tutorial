# 解释为何选择天赋

工作表位置：personal/OS解释.xlsx「事件」第 23 行。事件编号 E22。

正式签名：`解释为何选择天赋(arg1: Array<天赋>, arg2: 天赋)`

工作表动作：从【arg1：Array（天赋）】中选择【arg2：天赋】

## 事件标准

天赋效果为给予指定卡牌时，直接说明所给牌在当前局面的作用。

讲清天赋如何支持本局棋手、阵容或特定局势。

## 话术策略

已知天赋名称时，从所给牌、使用对象或用途起笔，省略重复交代的获取过程。

结合局势、棋手和阵容打法，解释目标天赋和棋手、阵容的联动关系

## 骨架库

- **E22-S01** 天赋+棋手 / 阵容 → 天赋对棋手 / 阵容的作用
- **E22-S02** （天赋适合特定局势，如残血）天赋+（棋手 / 阵容）+专门的局势条件 → 结合局势说明为何选择该天赋
