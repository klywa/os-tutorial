# 解释为何选择英雄

工作表位置：personal/OS解释.xlsx「事件」第 7 行。事件编号 E06。

正式签名：`解释为何选择英雄(arg1: Array<英雄>, arg2: 英雄)`

工作表动作：从【arg1：Array（英雄）】中选择【arg2：英雄】

## 事件标准

在实际候选中说明所选英雄的价值。

## 话术策略

结合局势、棋手和阵容打法，解释为何从多个英雄中选择这一个
1. 解释为什么选择该英雄（同购买）
2. 解释为什么选择的英雄比未选择的更好
3. 如果和已经在场上、手牌里的英雄有联动，可以点出联动。

## 骨架库

- **E06-S01** 英雄+阵容  → 英雄在阵容中的作用
- **E06-S02** 英雄+阵容+场上英雄 → 英雄之间的联动关系
- **E06-S03** （英雄有特殊功能） → 说清楚英雄的功能
- **E06-S04** （英雄有特殊功能）英雄+专门的局势条件 → 解释英雄在当前局势下的作用。

命中这条骨架时，在「说明与依据」分别注明特殊功能的来源、行动前可观察的局势条件，以及该功能在此局面带来的具体收益。
