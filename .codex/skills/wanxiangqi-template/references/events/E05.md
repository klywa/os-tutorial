# 解释为何从战场出售英雄

工作表位置：personal/OS解释.xlsx「事件」第 6 行。事件编号 E05。

正式签名：`解释为何从战场出售英雄(arg1: 英雄)`

工作表动作：从战场出售【arg1：英雄】

## 事件标准

辨明出售的是场上英雄，说明此时移出战场的收益。

## 话术策略

结合局势、棋手和阵容打法，解释为何此时出售该英雄
1. 如果是出售已上场的打工英雄，解释其只是临时用的打工英雄，并解释为什么现在卖掉（是为了腾空位？还是避免某些收益被分散？）
2. 如果是用来刷牌的英雄（预期就是要卖掉的），说清楚刷牌操作。
3. 如果本身有退场效果，结合当前棋手、局势解释如何利用退场效果，退场效果给谁。
4. 如果手上有遗志、传承等随机目标的效果牌，或类似小菟送福的棋手牌，可能是为了集中这些卡牌的收益（说明期望收益英雄是哪个）。如果有较高等级的阿科米亚核心并且处于终局，出售日落海英雄可能是为了让少数主力分配到更多的临时等级。
5. 如果在决赛阶段或形势紧急，可以卖掉一些主要用于提升等级但本身战力不强的英雄，换上对战局影响更大的英雄（如钟馗、太乙真人、海月）
6. 如果是用来触发其他效果或联动的卡牌（如露娜），可能是为了让其回到牌库，从而有机会再购买，触发新一轮的联动。
7. 某些技巧，例如：老夫子的效果虽然写了每回合限一次，但卖出再上老夫子之后，本回合可以再次触发。

## 骨架库

- **E05-S01** （英雄本身是打工、功能英雄）英雄+阵容 → 结合阵容，说明英雄并不是阵容长期需要的英雄
- **E05-S02** （英雄本身是打工、功能英雄）英雄+阵容+人口已满 → 结合阵容，说明英雄并不是阵容长期需要的英雄+出售腾出人口
- **E05-S03** （英雄本身有退场效果）→ 说明英雄退场的效果
- **E05-S04** （当前棋手、打法本身需要刷牌）棋手 / 阵容 → 说清楚刷牌操作
- **E05-S05** （英雄不是阵容主力）手上有遗志 / 传承 / 小菟助力等随机目标的牌 → 解释出售英雄是为了，防止效果分散
- **E05-S06** （英雄不是阵容主力，而是打工牌、过渡牌、提升等级的组件）英雄+人口已满+手上有钟馗、太乙、海月且场上没有+比赛后期或终局 / 形势紧急 → 形势紧急 / 决战时刻，腾出空位上阵对战局影响更大的功能英雄（如钟馗、太乙、海月）
- **E05-S07** （英雄可以和其他英雄进行联动）英雄+场上 / 手牌中联动英雄 → 说明联动效果
- **E05-S08** （阵容需要不断使用该英雄的登场效果）英雄+阵容+（牌库剩余数量） → 说明出售是为了让卡牌回到牌库
- **E05-S09** （英雄有某些和出售相关的技巧）英雄+技巧所需的条件 → 说明技巧
