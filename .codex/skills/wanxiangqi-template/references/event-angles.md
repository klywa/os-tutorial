# 解释事件索引

以下编号按 Excel「事件」页首次整理时分配，后续增删条目时保留原编号。选择事件后打开对应文档，通用标准叠加本事件的标准与策略。括号内条件要用本次知识来源判断。只可从本事件「骨架库」选取已编号的条目。

举一反三检查覆盖英雄取得（E01／E06／E07，含两轮拍卖）、效果牌取得（E11／E10／E12）与装备适配（E13／E14／E15）。分别判断动作、条件、收益及可用骨架。前端将各组三类动作相邻显示。正式名称、动作字段和键段顺序以 [正式注册表](../../../../src/condition/catalog-v04.json) 为准。E03、E04、E11、E16、E17、E18 是项目扩展，使用同样的键和条件校验。注册表中没有对应事件的旧骨架仅供回查。

本 Skill 的人工原句维护在各事件「案例库」的「已核实的人工话术样例」。核实正式事件与适用条件后加入，保留人工原句和来源。缺少轮次或必要条件的历史记录留在原节。
