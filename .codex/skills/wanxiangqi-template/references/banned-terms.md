# 玩家话术禁用词

可以直接编辑下表。每行记录一种不接受的写法、它在什么语境中有问题，以及可供选择的正式表达。写完每组话术都按当前表复核。替换时先核对官方机制，尤其要分清临时等级、永久等级、真实等级，以及谁获得效果。

| 禁用写法 | 适用语境 | 改写思路 |
| --- | --- | --- |
| 借……等级、借等级 | 英雄因其他英雄获得等级而受益。「借」听起来像等级日后要归还。 | 交代谁获得什么效果。司空震的效果要核实普通或觉醒形态，再写「其他英雄获得临时等级时，司空震……」。 |
| 追醒 | 购买或合成同名英雄以觉醒。 | 可写「追觉醒」，或直接说「使苏烈觉醒」等符合语境的完整表述。 |
| 加级 | 给英雄提供等级，或英雄获得等级。 | 明确主客体，按实际机制写「提高等级」「获得永久等级」「提供临时等级」等。 |

## 从旧稿中辨认相似问题

- 「给他套盾」可按官方效果写「为马超提供护盾」。涉及控制和法力值时，分别核实解锁等级和触发关系，长句可以只讲其中一项。
- 「给司空震补觉醒」放在上阵事件会让玩家去做另一个动作。如果当前事件是合成，则核实合成是否能够觉醒，再说明觉醒带来的变化。「集成临时等级」还需核对「集成」是否是笔误。
- 「用弈星拿完经验后，可以卖掉他」假定已经获得经验。要解释从战场出售弈星，核对这套打法为何需要收窄小菟助力的候选英雄。

## 教学笔记与模板共用的辨析

本表同时用于书面教学与播报。新发现的错误记录原写法、适用语境及核准的改法。引用卡牌原文时保留原句；下表用于审读作者自己的解释。

| 容易误写的表述 | 核对的含义 | 表达方式 |
| --- | --- | --- |
| 蓝条短、回蓝快 | 法力值上限、初始法力值、获得法力值的条件各自影响施法时机。 | 分别说明具体属性和触发效果；声称施法更频繁时核实实际收益。 |
| 自动成长 | 区分普通形态与觉醒形态，核对需要的操作或触发时点。 | 指明哪一种形态在什么情况下获得何种属性，以及收益归属。 |
| 补等级、带等级 | 是否提供临时等级、永久等级，或转移已有等级。 | 用对应卡面术语明确提供者、接收者及生效时间。 |
| 打出位 | 通常指暂时让英雄上场并触发登场效果所需的位置，也可能与手牌容量混淆。 | 先辨明位置：英雄需要上场时写「为露娜留一个上场的位置」；需要接收新牌时写「先腾出手牌空间」。 |
| 重触发、双触发 | 表述省去了再次执行的效果、触发者或结算次数。 | 按卡面写出完整动作，例如「对曹操使用临阵磨枪，再次触发他的整备效果」。若同一效果结算两次，指明哪一项效果结算两次。 |
