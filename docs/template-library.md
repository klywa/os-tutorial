# 话术模板库

【模板库】位于【全部笔记】和【看板】之间。模板按触发事件分组，每个组包含适用棋手、阵容棋手组合、同时成立的条件和多条等概率话术。此功能维护配置，不接收游戏事件或执行游戏端匹配。

## 浏览与维护

左侧选择事件，上方选择棋手或阵容，或用中英文逗号分隔多个条件值。多个词同时命中才显示，实体名称、别称和ID都可搜索。筛选具体棋手/阵容时会包含适用的通用组；“仅通用”单独查看通用组。

每个模板组左侧约占三分之一，集中显示卡牌、适用范围和全部条件；最大高度240px，超出后独立滚动。右侧显示全部话术，可直接逐条新增、编辑、删除，每组至少保留一条话术。编辑期间先保存或取消，再切换筛选；保存失败保留草稿。手机端上下排列，条件区最大高度200px。

管理员可以直接保存；编写员的新增、修改、删除及导入均进入私有提案。编写员也可提议维护事件和参数，管理员在“提案审核”中逐项采纳。浏览者只读和导出。过期保存或审批会提示重新核对，草稿不会自动覆盖正式内容。

事件与参数可以在网页配置。类型包括文本、数值、是/否和实体卡牌。文本建议值与数值范围是填写提示，不限制自由取值。文本、实体、布尔支持等于/不等于，数值另支持大于、小于、包含端点的比较和闭区间；组内条件均为 AND。

编辑模板时，可直接点击条件区的“新增事件参数”，或在参数下拉框选择“＋ 新增事件参数…”。参数标识自动生成，可修改；设置名称、类型及可选建议值/范围后，点击“添加并使用”即可选入条件。新参数属于当前事件，保存后其他同事件模板也可使用。参数定义与模板一起保存或提交审批，取消模板编辑不会单独保存参数。

话术用 `{parameter_key}` 引用同一事件的参数。网页的参数按钮可插入占位符；中文名称可修改，稳定英文 key 不应随意更名。`{{文字}}` 表示字面花括号。删除参数或改变类型前，先处理引用它的条件和话术。

## JSON 导入导出

在【模板库】顶栏点击【帮助】，可直接阅读本协议。点击帮助浮窗顶部的【导出帮助文档】，下载包含完整协议和两份 JSON 示例的 Markdown 文件，可离线阅读和分享；示例也可以单独复制或下载。

这是 JSON v2 的完整可移植协议；仍兼容导入旧版 v1，导出统一为 v2。请使用标准 JSON（双引号、无注释、无尾逗号），文件编码为 UTF-8。

[最小示例](examples/speech-template-library-minimal.json) 不依赖实体或阵容，可在空库导入；[完整示例](examples/speech-template-library.json) 包含四种参数、按名称引用实体和两条等概率话术。在网页帮助下方可以查看、复制、下载这两份原始示例。它们使用独立的 `help_minimal_event_v1` / `help_complete_event_v1` 事件 ID，不修改内置事件。首次导入会新增示例，再次导入会更新同 ID 的示例；实际使用时请为自己的内容分配新的稳定 ID。完整示例中的实体必须仍存在于目标站点的有效资料中，跨站导入前请核对。

每组标题右侧的“导出json”打开代码浮窗，展示该组当前正式内容及所需事件、参数定义，可一键复制；浏览者同样可用。复制权限不可用时会选中全部代码，便于手动复制。

### 顶层字段

| 字段 | 类型 | 必填与默认 | 含义 |
| --- | --- | --- | --- |
| `kind` | 字符串 | 导入必填 | 固定为 `"speech-template-library"` |
| `schema_version` | 整数 | 必填，无默认 | 当前固定为 `2`；兼容导入整数 `1`，不接受 `true` 或 `"2"` |
| `events` | 事件对象数组 | 必填，无默认 | 可以是 `[]`；可列出所需事件及完整参数定义；event_id 也可引用正式库已有事件 |
| `groups` | 模板组对象数组 | 必填，无默认 | 可以是 `[]`；导入不是全库替换 |

事件、组 ID 可省略，由预览生成；导出保留它们便于后续更新。参数使用稳定 key，不必填写 ID；v2 条件与话术没有 ID。

### 稳定 ID、参数 key 与唯一性

事件、组的 `id` 匹配 `[A-Za-z0-9_-]{1,128}`：1–128 位英文字母、数字、下划线或连字符。已有对象的 ID 应保持不变，改名不会创建新身份。`null`、空字符串及不合规范的 ID 不会被当作“未填写”。

同一文件的 `events` 内事件 ID 唯一，`groups` 内组 ID 唯一；可选参数 ID 在事件内唯一。实体和阵容笔记的 ID 属于外部资料，不受上述模板 ID 正则限制，例如实体 ID 可以含冒号。

参数 `key` 匹配 `[a-z][a-z0-9_]{0,63}`：小写英文字母开头，总长 1–64，只能含小写字母、数字、下划线；同一事件内唯一。条件和占位符使用 key，而非中文名称或参数 ID。更改 key、删除参数、改变类型之前，必须一起更新所有受影响的组。

### 事件与参数字段

| 事件字段 | 类型 | 必填与默认 | 含义 |
| --- | --- | --- | --- |
| `id` | 稳定 ID 字符串 | 可省略，预览生成 | 组可通过 `event_id` 引用；未提供 ID 时可用唯一 `event_name` 关联 |
| `name` | 非空字符串 | 必填，无默认 | 事件显示名 |
| `category` | 非空字符串 | 可省略，默认 `"未分类"` | 事件分类，可自定义；不是实体类别 |
| `parameters` | 参数对象数组 | 必填，无默认 | 允许 `[]` |

| 参数字段 | 类型 | 必填与默认 | 含义 |
| --- | --- | --- | --- |
| `id` | 稳定 ID 字符串 | 可省略 | 可选兼容字段；参数身份与条件、话术引用以 `key` 为准，导出不依赖参数 ID |
| `key` | 参数 key 字符串 | 必填，无默认 | 条件与话术引用键 |
| `name` | 非空字符串 | 必填，无默认 | 显示名 |
| `type` | 字符串枚举 | 必填，无默认 | `text`、`number`、`boolean`、`entity` 四选一 |
| `entity_categories` | 实体类别字符串数组 | 仅 `entity` 可用；省略时不限类别 | 提供时必须非空、无重复，且全部来自下方类别表 |
| `suggestions` | 类型化值数组 | 可省略，无预置建议 | 可为 `[]`；每项类型必须符合此参数，实体建议也须真实存在且类别匹配 |
| `min` / `max` | 有限数字 | 仅 `number` 可用；可分别省略 | 数值填写提示；同时提供时须 `min <= max` |

`suggestions`、`min`、`max` 都只是填写提示，不是允许值白名单或条件硬限制。例如建议范围 0–100 的数值参数仍允许条件值为 120；但参数定义中范围倒置、数字写成字符串、非法实体建议仍会报错。

| 参数类型 | JSON 值示例 | 规则 |
| --- | --- | --- |
| `text` | `"前期"` | JSON 字符串；条件值和建议值允许空字符串 |
| `number` | `3`、`2.5` | 有限 JSON 数字；不接受 `"3"`、布尔值、NaN 或 Infinity |
| `boolean` | `true`、`false` | JSON 布尔值；不接受 `1`、`0` 或 `"true"` |
| `entity` | `"小乔"` | 条件值和建议值均为名称字符串，按下方名称匹配规则解析，不填写实体 ID |

允许的实体类别为：

| 类别值 | 含义 |
| --- | --- |
| `players` | 棋手 |
| `heroes` | 英雄 |
| `equipment` | 装备 |
| `talents` | 天赋 |
| `derivatives` | 衍生物 |
| `effect-cards` | 效果牌 |
| `player-skills` | 棋手技能牌 |

实体名称先去除首尾空白，并限制在参数的 `entity_categories` 中查找；先精确匹配名称，没有名称命中才精确匹配别称，不做模糊或子串匹配。匹配到的各类别下，同名的全部版本（包括觉醒版）均关联、显示和监控；显式列出多个类别可同时匹配这些类别。未限制类别且命中多个类别时拒绝，须补充 `entity_categories` 消除歧义。未知名称整批拒绝，不会建立实体资料。已有记录保留旧名称或下架实体的历史档案，不能据此新建未知引用。

### 模板组与 scope 字段

| 模板组字段 | 类型 | 必填与默认 | 含义 |
| --- | --- | --- | --- |
| `id` | 稳定 ID 字符串 | 导入可省略，生成 `group_…` | 同 ID 更新同一组 |
| `name` | 非空字符串 | 必填，无默认 | 组显示名 |
| `event_id` | 字符串 | 与 `event_name` 至少提供一个 | 引用本文件或正式库已有事件 ID，提供时按 ID 查找 |
| `event_name` | 非空字符串 | `event_id` 省略时必填 | 仅以本文件内唯一事件名关联，不搜索正式库旧事件；重名时须使用 ID。两者同时提供必须指向同一事件 |
| `scope` | 对象 | 必填，无默认 | 同时填写下面两个键 |
| `conditions` | 条件对象数组 | 必填，无默认 | 可为 `[]`，表示无参数条件限制 |
| `utterances` | 字符串数组 | 必填，无默认 | 至少一条完整正文，组内每条等概率，可保留重复文本 |

| scope 字段 | 类型 | 必填与默认 | 含义 |
| --- | --- | --- | --- |
| `player_id` | 实体 ID 字符串或 `null` | 必填，无默认 | `null` 表示通用棋手；非空时须是有效 `players` 实体 |
| `lineup_note_id` | 笔记 ID 字符串或 `null` | 必填，无默认 | `null` 表示通用阵容；非空时须是已有 `lineup` 笔记，且同时指定其所属 `player_id` |

通用 scope 写为 `{"player_id":null,"lineup_note_id":null}`。非通用引用必须在目标资料中存在；本文件不会附带或创建棋手、阵容笔记。

### conditions、运算符与话术

| 条件字段 | 类型 | 必填与默认 | 含义 |
| --- | --- | --- | --- |
| `parameter_key` | 字符串 | 必填，无默认 | 当前事件中已声明的参数 key |
| `operator` | 字符串枚举 | 必填，无默认 | 下表中的比较方式 |
| `value` | 类型化值或数字对数组 | 必填，无默认 | 必须匹配参数类型和运算符，不能为 `null` |

| 运算符 | 可用参数类型 | value 形状 | 含义 |
| --- | --- | --- | --- |
| `eq` | 全部四种类型 | 参数对应的单值 | 等于 |
| `ne` | 全部四种类型 | 参数对应的单值 | 不等于 |
| `gt` | 仅 `number` | 数字 | 大于，不含端点 |
| `gte` | 仅 `number` | 数字 | 大于或等于，含端点 |
| `lt` | 仅 `number` | 数字 | 小于，不含端点 |
| `lte` | 仅 `number` | 数字 | 小于或等于，含端点 |
| `between` | 仅 `number` | `[下限, 上限]` 两个数字 | 闭区间，两端均包含，须下限不大于上限；相等也合法 |

所有条件为 AND，必须同时成立；不支持 OR、嵌套条件、额外运算符或字符串数字自动转换。网页维护配置，不在浏览器执行游戏事件匹配。

| 话术字段 | 类型 | 必填与默认 | 含义 |
| --- | --- | --- | --- |
| 每一项 | 非空字符串 | 必填，无默认 | 例如 `"留意{hero}的站位"`；直接写正文，不包成对象、不填写 ID |

每组多条话术等概率，没有 `weight` 或其他权重字段。`{parameter_key}` 引用参数，如 `{health}`；可以引用本组条件未使用但事件已声明的参数。`{{` 转义字面左花括号，`}}` 转义字面右花括号，所以 `{{提示}}` 显示为 `{提示}`。未知 key、未闭合或单个多余花括号都会报错。不执行 JavaScript、HTML 或表达式。所有非空名称、分类、实体引用字符串及话术正文须去空白后非空，最长 100000 字符；普通文本参数值不受此非空规则限制。

### 旧版 v1 兼容

v1 使用 `schema_version: 1`，实体值与建议值为 `{id,name}`，条件可带 ID，话术为 `{id,text}` 对象数组，可能含 `related_entities`。导入仍接受原协议并保留必要内部身份与历史信息；旧手动关联不再驱动卡牌或预警。v2 不接受 `related_entities`，条件不带 ID，话术只写字符串。所有导出统一为 v2；内部存储及审批使用稳定 ID，不应据内部数据格式编写便携文件。

### 导入、审批与导出边界

导入先检查并预览，确认后才保存。事件与组同 ID 更新，无 ID 生成新 ID，同名不同 ID 不合并。参数按 key 复用内部身份；条件和话术的内部身份用于审批与同步，系统按内容、顺序及替换位置保留，不出现在 v2 文件中。文件中省略的事件或组不删除；但同 ID 记录是完整替换，该记录内部省略的参数、条件或话术不会自动保留。更新事件定义还会校验正式库中所有依赖组，不能因只导入部分组而破坏其他组。

未知字段在顶层及每一层对象均严格拒绝，例如 `weight`、`private_notes` 或审核字段；不忽略未知字段，也不接受未知实体、重复 ID、重复参数 key、错误类型、无效引用。预览整批验证，错误时不产生可提交的修改；确认保存还会复核版本和依赖，过期内容须重新预览。预览不会写入正式数据。管理员确认后直接写入；编写员确认后生成私有提案，须由管理员采纳才进入正式库；浏览者可以阅读帮助和导出，不能导入。

导出全库、当前筛选或单组时都包含所需事件及完整参数定义。导出只含当前正式数据，不包含私有提案、账号、审核记录、实体预警基线、历史档案或同步状态。导出文件不嵌入实体资料和阵容笔记；跨环境导入仍需目标资料支持。网页帮助复制或下载示例本身不会向库中导入任何内容。

## 实体预警和同步

仅实际实体条件值及 scope 适用棋手自动关联。话术正文、参数建议值、旧版手动 `related_entities` 均不参与监控，也不提供手动关联或话术识别建议。移除实体条件或切换棋手后，其关联随之移除；仍有关联的历史实体及旧预警保留。实体有效机制、技能或数值变化会标记“待检查”，时间和图片更新不触发。编辑者登录后看到此前未提示过的变化汇总；关闭汇总只记录已知晓，不清除组上的预警。

管理员与编写员均可明确确认“已检查，无需修改”。修改话术或批准提案不自动确认实体变化，旧确认不能覆盖新变化。

正式内容保存在独立 `templates/` 数据域，并通过现有发布与双端同步流程同步。不同记录或不同条件、话术的修改可自动合并；同字段、删改、排序或定义依赖冲突由管理员在“模板同步冲突”中查看全部传入版本并确认。仅冲突记录暂停写入，其他模板继续可用。模板与解决事件统一事务保存；私有提案数据库随服务状态备份。
