# 话术模板库规则、协作与覆盖验收

以 2026 年 11 月 18 日确认的设计为准。模板审核沿用现有私有提案库，正式修改沿用知识笔记所在的版本同步流程。全库审订现有组，仅为常小娥灵活4人组补漏。

1. 更新共享条件目录及两端运行时，加入以阵容为参数的推荐事件。用同一组局面测试正式名、已登记别名、目标错误、缺值及从玩家读取阵容对象，保留当前打法和推荐目标各自的语义。清除带旧版标记的事件，同时覆盖空库初始化、旧库加载与同步。
2. 以一份编辑员提案验证原版、提交稿、管理员改稿和采纳结果。支持部分采纳、按版本重试及正式记录冲突后的核对。用隔离环境做双端版本同步及角色验证。
3. 修订模板技能，按正式实体逐项核对英雄、装备、效果牌及天赋。检查触发动作、棋手和阵容范围、30 字内的独立话术与来源。把有证据的知识补充提交到已有笔记的待审提案。
4. 通过模板导入预览和确认接口刷新正式库，读回检查稳定 ID、忽略记录和覆盖。分别核对购买与选择事件的页面、API、导出组数并更新覆盖报告。
5. 完成规则、审批、前端和技能验证，使用常驻服务管理器构建并重启。随后在独立调用中用浏览器核对 8765 和 5173 的首页、资源、模板规则帮助、事件筛选及审批页面。
