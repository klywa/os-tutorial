# 外网阵容手动匹配浮窗

用户明确要求新增浮窗，逐个指定外网阵容在知识库中的匹配项。沿用已确认的“阵容＋棋手”粒度，不代用户填入匹配。

## 实现
- Top10每行“指定匹配/修改匹配”，顶部“管理匹配”；原生dialog复用当前样式，列表切换当前榜单组合，显示网站组成，搜索同棋手阵容笔记并查看其组成。
- 手动指定优先于自动推断，保存独立的personal/lineup-usage-matches.json，按source_id×player_id记录note_id及组成指纹；每天同步保留，笔记改名按稳定ID继续有效。
- 提供恢复自动匹配。来源组成改变、指定笔记删除或棋手不符时显示待确认，不静默改用其他笔记。
- GET /api/dashboard/usage/matches返回当前组合、同棋手候选、手动状态和修订；PUT同路径保存或清除指定，检查修订与来源组成，409保留草稿。
- 浮窗保存不关闭，可继续下一项；切换和关闭保护未保存选择；保存后看板立即刷新。只保存用户显式选择，不改知识或旧名单关联。
