# 四篇通用知识笔记实现记录

目标：执行用户批准的四篇其他类笔记计划，复用 schema6 和现有编辑器。

- [x] 读取最新笔记及附件，核对本地文档证据，保留专题笔记。
- [x] 为子章节插入、层级调整及 key-value 默认值添加先失败测试。
- [x] 实现第 2—6 级章节编辑，移动和删除沿用完整章节块行为。
- [x] 生成四篇笔记提交草稿，并完成中文保义润色和说人话 review。
- [x] 经统一 commit 写入，读回核对身份、内容、证据和历史。
- [x] 执行 Python、前端、知识校验及桌面/窄屏检查。

默认：仅整合现有本地资料；缺证据章节留空；不部署、不提交 Git。

验证：前端 179 项、JSON 存储/正文 Python 23 项、编辑锁 Python 16 项通过；生产构建通过。wxq validate 全库 105 篇、957 张卡牌，无错误；skill quick_validate 通过。浏览器在 1440px、390px 中新增三级章节及 key-value，保存后刷新读回成功，无页面错误。原笔记所有节点 ID 和结论 ID 均保留，全部 35 条非空正文有直接有效证据。窄屏截图在 temp/general-notes-browser，内容审阅及证据快照在 raw/reports/general-notes-*。

测试环境：Vitest 临时目录指定为工作区 temp，避免 Windows 沙箱子进程读不到默认临时文件；Chromium 在获准提升权限后运行隔离 fixture，没有改动正式正文。
