# 话术模板库 v0.4

正式编审文件沿用 `kind: "speech-template-library"`、`schema_version: 3` 的文件容器。新版组填写 `syntax_version: "0.4"`、`extra_key`、`expression` 和整数 `priority`，话术使用 `{"id":"utterance_id","text":"…"}`。在网页可查看组的路径键、正式条件和句子。导入 v3 历史包时使用其原有语法解析。

模板组可包含 `wording_brief`，建议 400 字以内。网页在「说明与依据」旁显示「话术构思」，编辑和编审文件往返时保留该字段。模板技能将新组的构思原文传入 Gemini 首稿请求。

运行库由 `GET /api/templates/published` 提供。结构为 `解释事件 → 解释类型 → 额外信息键`，叶子是模板组数组，包含稳定组 ID、话术 ID、事件 ID、条件和优先级。迁移前的 S1 发布快照可通过 `?format=v3` 读取。

## 路径键

查看 [正式注册表](../src/condition/catalog-v04.json) 中事件对应的动作及键段顺序。例 `解释为何转移装备` 的键依次为目标英雄、原英雄、装备，`*-司空震-驱雷` 表示从司空震身上转出驱雷。半角连字符连接键段，完整的 `*` 匹配任意取值。无参事件用空键。棋手和阵容限制写成条件，编审界面的绑定会自动折入正式条件。阵容键填写正式短名。

匹配从通配最少的键开始，同级按优先级从高到低。每档合并各命中组可播的句子，再随机取一句。整档无可播句时降档，整级无可播句时回退到更宽泛的键。发布后的 `event_id` 供调用方做冷却和频次统计。

## 条件与槽位

| 用途 | 示例 |
| --- | --- |
| 盘面属性 | `我方.等级 == 5 and 我方.剩余能量 >= 3` |
| 可空对象 | `对手 != nil and 对手.主C != nil and 对手.主C.等级 >= 40` |
| 英雄在场 | `any(我方.场上英雄列表, .名称 == 动作.目标英雄.名称)` |
| 图腾在场 | `any(我方.场上衍生物列表, .名称 == "先知图腾")` |
| 过滤统计 | `count(我方.场上英雄列表, .阵营 == "河洛") >= 2` |
| 数值槽位 | `{{40 - sum(我方.场上英雄列表, .等级)}}` |
| 名称槽位 | `{{我方.主C.名称}}` |

条件可用 `and`、`or`、`not`、比较与 `any`、`all`、`none`、`count`、`sum`、`len`、`filter`。谓词内的 `.字段` 取当前元素，可读外部标量。用 `in` 查文本列表，用 `any` 查实体列表。读取混合卡牌来源的英雄属性时先限定卡牌类型。无参数事件的动作对象不声明字段。

单花括号是普通文字。双花括号槽位独立检查可空路径，必需值不可用时跳过该句。整数算术支持 `+`、`-`、`*`、`%`。卡牌列表使用顿号连接名称，空列表所在的句子跳过。

购买动作的候选列表包含选中牌。旧输入可以提供独立英雄数或手牌数，新局面通过 `len` 读取完整列表。旧输入读取缺项时保留未知状态。新版输入的建议发展阵容事件在待识别局面触发，目标阵容来自动作参数。

合成英雄和从手牌出售英雄的额外信息键都是英雄名称。`动作.英雄` 使用操作前的英雄状态，手牌列表也使用操作前快照。合成结果可提供 `动作.合成后已觉醒` 和 `动作.合成后等级`。判断觉醒或等级门槛变化时须先检查对应结果字段存在。手牌和战场出售通过事件名区分。
