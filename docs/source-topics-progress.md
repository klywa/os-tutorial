# 外部内容主题字段与本地自动提取

本轮实现五个可编辑字段、独立CPU主题队列、阵容名单与待确认管理。正式阵容名单尚待用户提供；没有自动采用现有知识笔记作为名单。

## 使用入口

外部内容 → 编辑内容：四类主题多选与忽略。更多筛选支持主题交叉筛选；同字段任一命中，跨字段同时满足。已忽略入口独立管理，不能全选、复制路径，恢复后补提取。

外部内容 → 主题提取与阵容名单：查看队列、暂停/继续、重试失败；粘贴正式阵容名、维护已确认别称、停用；处理未知候选时有来源、原文及上下文。只有正式名称或确认别称精确匹配才自动映射。停用/改名保留已经映射的稳定ID。

自动只填棋手和阵容；英雄、卡牌和忽略仅人工。人工值及明确清空优先，棋手/阵容可恢复自动值。自动提取不登记知识、不触发核对或finish。
