# 外部内容选取与复制优化

已实现暂存提速、独立操作状态、通用 Prompt 模板和左侧全选。

- 暂存使用 `workspace.sources(..., include_knowledge=False)`，跳过知识笔记及证据关联扫描；一次加入在 SQLite 事务中复用一次来源查询，维护顺序、去重、忽略过滤及修订号。原有来源查询默认行为不变。
- 加入期间立即打开 Prompt，可编辑模板；路径及 Prompt 快照等待本次修改成功。修改失败时保留选择并阻止依赖复制，成功重试后恢复；成功加入只清除此次提交的选择。快照请求遇到本地并发修改会重新核对，最多三次。
- Prompt 浮窗提供一套可保存模板，按项目存入当前浏览器 localStorage；使用 `{阵容名}`、`{内容列表}` 单次替换，插入内容不递归解析。保存模板保留本次草稿，显式重新生成后应用。草稿仍保存在 sessionStorage，关闭重开和刷新保留。
- 保留复制前 fingerprint 校验和剪贴板失败时的完整文本手动复制。过期草稿修改阵容名也不会隐式更新来源列表。
- “全选本页”放在列表上方最左侧，支持半选和取消本页选择，保留其他页勾选；暂存区位于选择区上方，取消两栏吸顶以免滚动遮挡。

真实数据核查确认来源仍有826条（805条外部内容、21条已忽略）。旧本地后端启动于修改前；首次来源查询超过20秒，而前端将尚未加载的空数组直接显示为0。真实数据性能剖析发现默认来源查询调用完整笔记投影，其中正文及历史的 deepcopy 占约15秒。
