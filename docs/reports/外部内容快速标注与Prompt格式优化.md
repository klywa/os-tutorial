# 外部内容快速标注与 Prompt 格式优化

已完成并更新两个实际入口。

- 外部内容列表增加独立标签与备注行内编辑；标签可搜索、多选、新建、移除，失焦保存，Escape 取消。
- 保存按来源串行执行，返回后更新单行；轮询保留草稿，失败可重试，其他行编辑和文字稿阅读继续可用。仅修改标签或备注不提取主题。
- 编辑 Prompt 使用浮窗，带“复制”按钮。逐项输出标题、存在的本地文字稿绝对路径或网页链接，以及可选备注；保留人工草稿，复制前检查资料及暂存顺序变化。
- 新增标签候选和暂存 Prompt 快照接口。Prompt 使用只读一致性校验，不等待知识写锁。

验证：386 项 Python、63 项前端测试、生产构建和知识 validate 通过。双入口浏览器覆盖标签交互、失焦、轮询、Escape、失败重试、并发阅读、连续保存、Prompt 复制及过期保护，均无页面异常；420px 无横向溢出。

确认无活动采集后更新后端，三个入口的新接口均返回 200；两个实际 UI 入口只读验收通过。浏览器写入验证使用隔离测试库，正式知识内容哈希未改变。
