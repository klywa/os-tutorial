# 万象棋战术手册

在项目根目录运行：

```powershell
powershell -NoProfile -File frontend/start.ps1
```

脚本安装锁定依赖、构建前端，并在 http://127.0.0.1:8765 启动本地服务。首次需可用 Node.js/npm 及项目 `.wxq-runtime`。终端 Ctrl+C 停止服务。`-NoBrowser` 不打开浏览器；`-Port 8766` 更改端口。

开发：先运行 `..\.wxq-runtime\Scripts\python.exe server.py`，另开终端在此目录运行 `npm run dev`。生产使用同源页面，开发端口 5173 通过 Vite 代理 API。

笔记编辑会同步索引、中文 Markdown 和阵容 JSON。人工修订保留，技能导入冲突显示待核对。meta 缺失是待确认，禁用条件缺失不会被当作可玩。

“爬取”支持B站多关键词搜索、日期（北京时间，含起止日）、播放量及秒数时长筛选。默认自动处理；切换预览模式后勾选结果再处理。搜索条件可保存，默认每个关键词扫描100条、每批处理50个新视频；搜索覆盖范围以B站实际返回与扫描上限为准。重复视频合并关键词与批次，投稿全部分P分别导出文字稿。

“UP主监听”配置名称、空间URL、起始日期与可选关键词。UID去重；可停用、编辑、单个或全部立即检查。默认每天北京时间09:00检查，可修改；本地服务需运行，关闭网页不影响，服务重启后补查，任务忙时顺序执行。失败检查不推进成功时间；界面可重试失败任务或恢复停止的任务。

任务队列保存在 `raw/crawler/queue.sqlite3`。搜索扫描使用独立的2路线程池，不等待下载或转写；视频在独立工作进程并行处理，默认2个，可在“同时处理视频数”设置为1–4个。不同批次公平派发，同一BV仍只处理一次；降低上限不打断已开始的视频。搜索接口请求全局限速。服务重启恢复中断任务，CLI和网页共享BV处理锁；多个视频同时导出文字稿时短暂等待共享写锁。

每个任务旁有“删除”按钮：任务从列表移除并停止继续扫描和派发；不再被其他任务引用的运行视频会取消，恢复素材保留，已采集内容和文字稿不删除。共用视频继续为其他任务处理。删除采用内部墓碑保留采集审计信息，已删除任务不能被迟到的后台结果或重试复活。

转写成功并确认文字稿有效后清理临时音视频，保留原始ASR、修正版、元数据、纠错记录和关键帧；失败保留恢复素材。网页自动处理止于文字稿，不调用知识沉淀finish，也不覆盖人工标题、备注和文字稿。手动添加链接仅登记；通过“爬取”启动自动处理，核对与知识整理仍使用技能。

“外部内容”支持筛选、跨页选择、选择全部筛选结果、文字稿预览和“监听此UP主”。复制路径仅复制实际存在的文字稿绝对路径，每个文件一行，缺失文件计数跳过。修改筛选条件会清空选择；剪贴板失败时展示路径供手动复制。

匿名访问遇到B站登录或风控错误时，在“B站连接设置”填写本机Netscape格式cookies文件路径后重试；文件内容不进入数据库或API。请勿同时运行多个不同版本的服务；默认端口占用时先关闭旧版工具。

API：`GET/PUT /api/crawler/settings`；`GET/PUT/POST /api/crawler/searches`（读取/保存条件/启动）；`GET /api/crawler/jobs[/ID]`；`POST /api/crawler/jobs/ID/start|stop|resume|retry`（start/retry可带bvids）；`GET/POST /api/crawler/creators`；`POST /api/crawler/creators[/UID]/check`；`GET /api/sources/ID/transcript`；`POST /api/sources/paths`（ids）；`POST /api/sources/ID/creator`。服务限本机同源访问；文字稿只按登记ID读取raw目录内文件。

删除接口：`DELETE /api/crawler/jobs/ID`（JSON请求体 `{}`），幂等；删除后详情返回404。`PUT /api/crawler/settings` 接受整数 `parallelism: 1..4`，旧配置自动默认2，无需迁移用户输入。

验证：`npm test`、`npm run build`；项目根目录运行 `.wxq-runtime\Scripts\python.exe -m unittest discover -s .codex/skills/wanxiangqi-knowledge/tests` 与 `wxq.py validate`。

全局任务栏位于主导航下方，在所有页面展示正在下载、正在转录、整理中、排队和已停止数量，支持收起及显示排队视频，每2秒更新。视频支持“停止下载”“停止转录”“继续处理”和“删除视频任务”；不在对应阶段的停止按钮置灰。停止立即中断工作进程树并保留文件及ASR检查点；恢复按检查点继续，最近尚未落盘的少量分段会重算。共用视频操作影响所有关联批次。

采集任务改为纵向列表，删除任务始终在每行操作区可见；选中详情另有“删除当前任务”。批次阶段停止同时停止后续派发；继续时先恢复批次派发，再继续对应已停止视频。视频删除只取消处理，保留来源和已生成文字稿。

全局接口：`GET /api/crawler/activity`。视频操作：`POST /api/crawler/tasks/BVID/stop-download|stop-transcribe|resume|delete`；批次阶段停止：`POST /api/crawler/jobs/ID/stop-download|stop-transcribe`，请求体 `{}`。停止与派发递增运行编号，旧进度和结束回调无法覆盖恢复后的运行。FFmpeg使用临时文件，成功后原子替换，避免恢复复用中断输出。

## 卡牌图片、实体 chip 与阵容概览

在项目根目录运行 `.wxq-runtime/Scripts/python.exe .codex/skills/wanxiangqi-knowledge/scripts/wxq.py sync-card-images`，按实体已有官网URL增量缓存缩略图与卡面到 `entities/assets/`。`sync-entities` 也同步图片。失败保留旧图，可重复命令重试；无需在网页运行时访问官网图片。

卡牌接口返回 `thumb_url`、`image_url`、`image_status`。`GET /api/cards/实体ID/images/thumb` 或 `/images/image` 仅返回清单内登记文件。卡牌库、文字chip和阵容概览共用本地图片与详情缓存。

笔记正文正式名称按最长匹配渲染chip，别称不命中（如“瑶妹”保持原文），代码与链接不改写。结构化成员按实体ID显示；同名普通/觉醒不默认选择，先选择具体卡牌。悬浮/键盘聚焦打开，点击固定、Esc/关闭按钮关闭，手机点击操作。卡牌候选仅影响当前浮层，不写回笔记。

“编辑笔记→阵容概览与站位”配置方案、四行七列站位、装备、备选、阶段说明与结论引用、天赋、效果牌及棋手能力。先点击格子，再选英雄；在另一格选择已有英雄即移动，装备保留。成员名单仍来自阶段组成与后期组合，未知站位不自动安排。

`meta.overview` 为可选版本1结构，包含 `presets`；每个方案通过 `variant_id` 引用现有后期组合，存展示补充和实体/结论ID。旧笔记使用只读默认投影；保存后才写入JSON与索引，受修订号和人工元数据保护。路线及组合的选择按笔记ID在两个阅读页面间保留。本轮不改变独立HTML导出。
### 阅读详情栏与任务恢复

正文区域宽度达到1160px时，卡牌详情展示在320px右栏：悬浮/聚焦预览、点击锁定，支持解锁、关闭与Esc。窄屏和手机仍使用浮层。无运行任务时全局任务栏默认收起。

爬取页的批次与视频任务采用自动换行卡片，底部图标支持停止下载、停止转录、继续/重试及删除。错误摘要附操作建议，完整日志可展开。UP主编辑使用弹窗，UID不可更换；`DELETE /api/crawler/creators/{uid}` 删除监听并停止继续发现，保留历史、已派发视频和文字稿。

B站-352/-401/403/412/429会自动进入持久化冷却：1、5、15、30、60分钟，之后每小时继续尝试。搜索、UP主检查与视频下载均支持；新会话重新载入已配置的cookies，刷新官网会话和WBI签名，下载重取链接。页面隐藏冷却次数和倒计时，按等待采集或排队展示；后台成功后清除退避记录。停止/删除不会被复活，停用监听取消其等待中的检查；登录失效需用户更新登录信息，验证码需在浏览器手动完成。程序不会将风控当作空结果，也不自动读取其他浏览器凭据。

旧文字稿索引缺哈希时按既有输入/输出验证，备份至`raw/reports/index-upgrades/`后补齐；原始ASR旧导出保留`legacy_raw`格式，不覆盖正文。坏音频及转写检查点隔离至来源目录`failed-media/`，重新获取音频并核验时长。下载断连最多3次退避重试，每次重新获取下载信息并保留可续传文件。


### 外部内容编辑

宽屏筛选集中为一行，日期/数值条件通过更多筛选打开；窄屏使用搜索框和筛选弹窗。列表采用紧凑行，长备注可展开，跨页选择和文字稿路径复制规则保持。

编辑内容弹窗包含资料和文字稿两个独立保存页签。资料通过来源ID保存人工覆盖值，明确清空也会保留；后续采集不覆盖。链接只能指向同一来源，展示批次与实际任务归属分开。PUT /api/sources/{id} 携带列表revision，冲突返回409。

GET/PUT /api/sources/{id}/transcript 使用独立revision，路径仅从登记索引读取。保存人工文字稿前在raw/reports/transcript-edits/保留原文，短暂写锁内更新文字稿与索引，失败回滚，中断事务在启动或下次访问时恢复。人工版本受自动导出保护，列表标明人工编辑/待核对，不自动更改知识结论。


### 外部内容主题

外部内容 → 编辑内容可维护主题棋手、阵容、英雄、卡牌及忽略状态。主题选择器可搜索并多选；更多筛选中，同字段任一命中、跨字段同时满足。已忽略内容从正常列表、全选及路径复制中排除，可在“已忽略”恢复。不会停止已派发视频。

“主题提取与阵容名单”提供独立队列进度、暂停/继续、失败重试、正式阵容名导入、名称/确认别称编辑和停用。名单为空时只填写棋手，阵容候选进入待确认；导入或确认别称后直接重新匹配已有候选。停用保留历史ID。单条内容支持重新提取；人工值包括明确清空优先于自动值，棋手/阵容可恢复自动值。

本机运行 `frontend/topic_worker.py --root <项目绝对路径>`，服务启动时自动启动，独立进程锁避免重复。每20秒补查有效文字稿，采集导出后也即时入队。输入变化以标题及全文SHA256识别；分P分别处理。队列存放 `raw/crawler/topics.sqlite3`，原ASR和知识状态不变。

本地模型位于忽略目录 `.wxq-runtime/llm/`：官方 Qwen3-1.7B Q8_0 + llama.cpp b11712 Windows CPU运行时。manifest.json记录来源及SHA256；运行 `python frontend/install_topic_model.py` 可断点补装，`--verify-only` 离线核验全部文件；CPU四线程、GPU零层、禁用思考，仅127.0.0.1随机端口及随机API密钥，空闲5分钟释放。完整文本按实际token分块、覆盖所有分块后归并主要话题；没有语音不凭标题打标签。模型失败最多校验重试一次，旧有效主题保留。

接口：`GET /api/topics/catalog|queue|lineups|candidates`；`POST /api/topics/control`（pause/resume/retry/extract，单条source可选）；`POST /api/topics/lineups`导入names；`PUT /api/topics/lineups`按ID更新；`PUT /api/topics/candidates/{id}`确认target/remember_alias或reject。来源PUT沿用revision，支持四类主题数组、ignored和restore_topics。自动主题结果与人工覆盖独立保存。

正式批量运行先通过20条真实样本验收；队列门禁与模型/提示版本绑定。详细样本、速度和剩余工作见 `docs/source-topics-progress.md`。

### 分类目录与预设阵容

全部笔记按阵容、棋手、其他折叠分组。阵容目录使用共享名单，展示成员与关联笔记数量；无笔记项显示占位，不生成笔记。现有阵容笔记保留在未归类区，管理员在“管理阵容名单”确认关联，一套阵容和一篇笔记均可多重关联。对局助手仍只列有实际攻略的打法。

名单可新增、改名、修改英雄成员/确认别称、排序、停用和明确合并。修改携带条目revision，冲突409保留草稿；合并以稳定重定向保留人工主题与历史引用，同步不恢复已合并项。成员修改会重新核验自动组成映射，人工确认不被覆盖。

网站同步从datawxq.com当前默认版本、万象大赛、最近7天和最少50场获取全部分页。完整英雄集合相同才合并，按登场率、场次、名称确定来源正式名。网站标题由其公开展示规则生成，保留原响应；同名但组成不同的条目分别保存，有歧义时不自动映射。同步先预览差异，应用后保留人工值，不删除缺失项。

接口增加 `POST /api/topics/lineups/preview|apply|merge`、`PUT /api/topics/lineups/bind`、`GET /api/topics/lineup-suggestions`；GET notes返回lineup_ids。名单GET返回heroes/note_ids/sources/sort_order/revision/merged_into；POST/PUT新增或更新完整资料。主题control新增reextract，返回批次与名单修订。

主题提取先识别主要话题，再用名单核对已有阵容候选及完整成员证据；后一步不能新增棋手或阵容主题。名称/确认别称唯一命中，或完整且可核验英雄集合唯一对应，才自动映射；其他保留待确认。全量重提取在新版真实样本通过后启动，缺稿等待，忽略跳过，人工值与知识正文不改动。详见 `docs/lineup-directory-progress.md`。

### 常用名与变阵

名单保留原名及稳定ID，`common_name`非空时作为`display_name`统一展示。原名、常用名和已确认别名均可搜索；共享名称不自动合并。明确清空或人工修改受同步保护。

网站同步同时获取主列表全部分页及每套主阵容的详情变阵，使用相同版本/模式/7天/50场门槛，保存原响应和统计。重复页、缺失详情、数量不符或身份异常均拒绝应用。变阵按完整成员集合去重，可关联多个主阵容；只在阵容内部展开，不生成笔记、目录项或独立主题。已有人工说明和路线继续沿用正文。

“管理阵容名单”可维护常用名、多别名及变阵关联；“命名待确认”提供公开来源、引文、成员对照和归属选择，确认常用名、收为别名或驳回均检查修订号。名单变化优先重匹配已保存的原文证据；只有组成证据不足时才重新分析文字稿。

新增`GET /api/topics/lineups/{id}/variants`、`PUT /api/topics/lineups/variants`及`GET /api/topics/lineups/naming-candidates`、`PUT /api/topics/lineups/naming-candidates/{id}`。主阵容返回common_name/display_name/variants；命名裁决携带主阵容revision和candidate_revision。外部内容仍以主阵容ID保存主题，支持棋手/阵容/英雄/卡牌四类筛选，同字段任一命中、跨字段同时满足。


### 阵容名单快速编辑

在“全部笔记 → 管理阵容名单”直接修改常用名、别名；别名支持回车、逗号和换行粘贴去重。多行草稿统一“保存全部”，筛选不清草稿。原名、英雄组成、排序和笔记关联使用“详细编辑”；阵容占位页可直接打开当前项。网站同步与命名建议折叠在下方。

批量接口 `PUT /api/topics/lineups/batch` 接收 `{items:[{id,revision,common_name,aliases}]}`，一次事务保存；任一修订冲突返回409和lineup_ids，整批不变，网页保留草稿。刷新服务器资料后核对冲突行，再显式重试或放弃。

`DELETE /api/topics/lineups/{id}` 接收 `{revision}`，仅移入“已删除”；`POST /api/topics/lineups/{id}/restore` 接收 `{revision}` 恢复删除前启用状态。历史ID、主题、笔记与文件保留，已删除项不进入新匹配及目录，网站同步不复活。管理确认使用页内弹窗。

### 关键词“或”条件与严格匹配
关键词搜索可添加/删除“或”条件，粘贴多行会拆成多个条件并去重。每个条件分别请求B站，独享扫描上限；批次处理上限共享。严格匹配默认开启：同一行按空白分词，所有词必须出现在标题中（顺序不限、不区分大小写），不同条件满足任意一项即可。只检查标题，不使用简介、别名或语义扩展；关闭后沿用B站搜索结果及数值/日期过滤。配置可保存恢复。标题不匹配计入扫描量，不登记或派发；任务详情显示每条件扫描量和跳过数量。历史批次缺少strict_match时沿用旧规则，UP主监听不受该开关影响。

### 字幕优先与任务统计
网页采集先复用有效文字稿，按实际分P优先人工中文、其次B站自动中文字幕（同类简体优先）；字幕有效时只获取字幕并导出时间轴文字稿，不下载音视频、不执行ASR或自动取帧。无可用中文或候选内容无效时回退large-v3；登录、风控和网络失败单独处理及重试，不当作无字幕。沿用本机cookies与限速。
字幕保存于来源文件夹的subtitle.raw.json、subtitle.corrected.json、subtitle-source.json，原文件与校验信息保留，文字稿和来源接口标记transcript_origin=bilibili_subtitle。仍为待核对，不改变沉淀状态。支持人工编辑、路径复制与主题提取；人工产物不覆盖。检查/获取字幕阶段可“停止下载”，未进入ASR时不能停止转录；已有运行任务不强制中断。
任务统计改为单行标签与数字，窄屏仅统计栏内部横向滚动。

阵容笔记关联：阅读、编辑和占位页均可打开“关联阵容”。唯一常用名／确认别名完全匹配时自动关联空阵容；已有主笔记须选择替换或笔记级变体。章节级只复制 wanxiangqi-knowledge 整合指令。关联与改名通过 `POST /api/topics/lineups/associate` 同时携带 `revision`、`note_revision`；共享锁与操作日志支持中断恢复。人工解绑或替换移出的笔记不自动挂回。阵容合并迁移角色及排除，双主冲突返回409。

### 采集访问恢复
分P发现不依赖媒体格式，详情接口受限时仅复用完整登记元数据或允许无媒体格式的元数据解析，不猜测分P。字幕请求失败记录真实原因，刷新会话一次后重试，仍不可用可回退独立音频及large-v3；`subtitle-fallback.json`保留诊断。音频也受限则持久化退避。`network.sqlite3`协调跨进程请求开始限速和分接口冷却，`session-cookies.txt`为本机忽略目录中的会话缓存，不上传、不显示内容。任务结构化错误和历史诊断保留在队列数据库，调度器仅补偿未写结果的异常退出；成功或排队状态不投影旧来源错误。启动时仅一次恢复仍有效的相关失败任务，停止／删除不恢复。已完成转写无需联网即可恢复导出。


### 链接采集与暂存

“爬取 → 链接采集”逐行输入视频URL、BV号或B站短链接，先检查再启动。p=N仅处理该P，未指定则处理全投稿；共享产物按各批次需求计算完成状态。无关键词或日期筛选。

外部内容每页25条，可选择本页或全部筛选结果；勾选、筛选和页码保留页面会话，改变筛选清空临时勾选。“加入暂存”向项目唯一暂存区累加，刷新和服务重启保留；忽略或失效来源移出。复制文字稿路径与编辑prompt使用全部暂存内容。Prompt是本次完整草稿，关闭重开保留；暂存变化须显式重新生成，复制前核验路径快照。

名单管理支持清理预览：仅无明确笔记关联的项目可移入已删除，先备份并再次校验名单版本。恢复不改正文。

新增API：POST /api/crawler/links（text、preview）；GET/POST /api/sources/staging；DELETE /api/sources/staging/ID；POST /api/sources/staging/clear（revision）、paths；POST /api/topics/lineups/cleanup/preview、apply（token）。

下载字节不足、超时及连接重置按网络中断处理。每轮最多3次，后续1/5/15分钟最多3轮，重启保持计划；手动重试重置轮次。远端长度、对象标识或格式变化，以及不支持续传时隔离旧分片，禁止拼接。停止/删除不自动恢复。

### 外部内容快速标注与 Prompt

每条外部内容可点击“标签”或“备注”直接编辑，焦点离开整个编辑区域后保存，Esc取消。标签可搜索、多选、输入新标签后回车或点击添加；已有备注复用。单行保存串行使用成功修订号，其他行和文字稿阅读保持可用；错误保留草稿，核对后重试。标签与自动主题分类分开，`GET /api/sources/tags`仅汇总来源登记中的已使用标签（含已忽略来源），`PUT /api/sources/{id}`支持`tags:string[]`，仍携带revision。

“编辑prompt”以浮窗打开，提供“复制”按钮。`POST /api/sources/staging/prompt`返回按暂存顺序排列的`items:{id,title,location,notes}[]`、revision及fingerprint；location优先有效本地文字稿绝对路径，否则网页链接。每项格式为`- 标题：路径或链接（备注）`，无备注省略括号，多行备注生成时合并为一行；标题为空使用来源ID，标签不写入Prompt。人工草稿关闭重开保留，复制前核验相关资料，过期时显式重新生成。“复制文字稿路径”接口及其仅复制有效本地路径的行为保持不变。
